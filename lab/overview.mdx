## How I use it

- **Prototypes start here.** New directions get a lab page before they touch the real site, so I can compare options side by side and decide by eye.
- **Decisions get written down.** Every iteration in the process log records what I tried, what I kept, and why. The rejected directions are as useful as the kept ones.
- **The design system is the source of truth.** It documents what's actually in the code (`landing.css`, `style.css` and the snippets), so it stays honest.
